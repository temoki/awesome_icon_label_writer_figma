# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Overview

A Figma plugin that renames text nodes containing a single Font Awesome icon glyph to
`[FA{version}-{style}] {icon name} / {unicode}` (e.g. `[FA6-Solid] credit-card / f09d`).
With no selection it scans the whole current page; with a selection it scans the selected nodes and their descendants. Font Awesome 5 and 6 are supported.

## Commands

- `npm run build` — webpack build into `dist/` (`dist/code.js`, `dist/ui.html`, referenced by `manifest.json`). Add `-- --mode=production` for a production build without inline source maps.
- `npm run watch` — rebuild on change while testing in Figma (Plugins → Development → Import plugin from manifest).
- `npm run lint` — ESLint over `src/**/*.{js,mjs,cjs,ts}` (typescript-eslint recommended).
- `npm run codegen` — regenerate `src/icons_fa5.ts` / `src/icons_fa6.ts` from the Font Awesome GitHub metadata (`icons.json` on the `5.x` / `6.x` branches). Requires network access and Node with global `fetch` (see `.node-version`).

There is no test suite; verify behavior by running the plugin in Figma.

## Architecture

Standard two-context Figma plugin:

- **`src/code.ts`** (plugin sandbox, has the `figma` API): on launch, collects text nodes (selection or `figma.currentPage.findAll`), keeps those whose content is exactly one character and whose font family starts with `Font Awesome`. The version is the third word of the family name (`Font Awesome 5 Free` → `5`; anything else falls back to the FA6 map), the style comes from `fontName.style`, and the icon name is looked up by the glyph's hex code point. Nodes whose name already matches are skipped. Matches are selected and zoomed into, then sent to the UI. Renaming happens only after the user confirms.
- **`src/ui.html`** (iframe UI): plain HTML, CSS and an inline `<script>`, with no bundled UI entry. Webpack's `HtmlWebpackPlugin` copies it to `dist/ui.html` (the `chunks: ['ui']` setting refers to a chunk that doesn't exist, so nothing gets injected).
- **Message protocol** (`postMessage` between the two contexts):
  - plugin → UI: `renamable-nodes-found` `{ renamableNodes: {nodeId,newName}[], isSelectionMode }`, `renamed` `{ count }`
  - UI → plugin: `rename` `{ renamableNodes }`, `exit`
- **`src/icons_fa5.ts` / `src/icons_fa6.ts`**: generated by `codegen.js` as a `Map<unicodeHex, iconName>`. Don't edit them by hand; they are large single-line files, so avoid reading them whole.

`manifest.json` uses `documentAccess: "dynamic-page"`, so `figma.currentPage.loadAsync()` must be called before `findAll`/`findOne` on the page. Network access is disabled (`allowedDomains: ["none"]`).
